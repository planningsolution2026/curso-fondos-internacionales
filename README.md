# Curso: Fortalecimiento de capacidades para fondos internacionales

Sitio web estático preparado para GitHub Pages bajo el usuario **planningsolution2026**.

## Publicación rápida

1. Crea en GitHub un repositorio público llamado `curso-fondos-internacionales`.
2. Desde esta carpeta ejecuta:

```bash
git init
git add .
git commit -m "Publicar curso Planning Solution"
git branch -M main
git remote add origin https://github.com/planningsolution2026/curso-fondos-internacionales.git
git push -u origin main
```

3. En GitHub: **Settings → Pages → Deploy from a branch → main / (root) → Save**.

La web quedará en:

`https://planningsolution2026.github.io/curso-fondos-internacionales/`
